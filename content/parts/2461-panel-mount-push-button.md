## About

The panel mount push button behaves like the [Tactile Button Switch](https://guides.ioref.org/parts/0356) in that an electrical connection is only made when the button is pressed. The distinguishing factors are that it has only two leads (towards power and ground) and that it has a small tightenable plastic ring that allows you to fasten the button to a panel, for developing a physical interface with only the button head peeking out and the rest of the circuitry obscured.
